# Documentation map

Current Taildown documentation has distinct maintained sources:

- [README](../README.md): project introduction and source installation.
- [Authoring guides](../docs-site/README.md): getting started, syntax, components and styling; these sources build the public website.
- [Language contract](../SYNTAX.md): detailed syntax semantics.
- [Architecture](../tech-spec.md): current compiler, editor and runtime boundaries.
- [Editor guide](../editor/README.md): files, design settings, shortcuts, recovery and offline use.
- [Examples](../examples/README.md): complete authored documents and compilation.
- [Contributing](../CONTRIBUTING.md), [repository rules](../PROJECT-RULES.md), and [scripts](../scripts/README.md): development and verification.
- [Syntax tests](../syntax-tests/README.md): executable fixture scope and expectation review.

The former phase plans, session summaries, implementation-status reports, and their old rendered copies are preserved under [history/](history/README.md). They are historical records, not current contracts or build inputs. Preserve useful new architectural rationale in the architecture guide rather than adding a second status document here.
