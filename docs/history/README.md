# Historical records

This directory preserves earlier Taildown development plans, assessments, session reports, and rendered snapshots. They describe past work and proposals. Their API claims, test counts, known failures, commands, links, and deployment directions may be obsolete.

Do not use these files as contributor instructions or ship their compiled HTML. Use the [current documentation map](../README.md). This archive is excluded from documentation and example builds; its content is preserved for historical reference rather than maintained as an alternate specification.
